Fetch the readable text content from a specific HTTP or HTTPS URL. Use this after web_search when a result page needs to be read directly, or when the user provides an exact URL. It strips scripts, styles, and HTML tags and returns concise page text.

External site access may be restricted by the allowed-websites allowlist (config web.allowedSites): when entries exist, only listed origins plus localhost (127.x / ::1) are fetchable; https://*.example.com allows subdomains while the apex example.com must be added separately. When a fetch is denied by the allowlist, do NOT retry the same URL — tell the user which entry to add in the desktop settings (设置 → 允许的网站) and wait for their confirmation.
