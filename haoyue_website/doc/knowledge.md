# 知识中心：笔记本、来源与可检索的经验

如果说记忆（MEMORY.md）是每次对话都注入的「工作备忘」，知识中心就是可按需检索的「档案柜」。这一版把档案柜升级成了真正的知识管理体系：**笔记本 → 来源 → 条目** 三层结构，让每条知识都有自己的位置和出处。

## 三层结构怎么理解

- **笔记本**是归组维度。每个工作区自带一个不可删除的「默认笔记本」，Agent 自动沉淀的知识都落在这里；你也可以按项目、主题自建笔记本，把「前端踩坑」「部署手册」「会议纪要」分开管理。
- **来源**是知识的出处。一段粘贴的文本、一个网页 URL、一个本地文件——导入时自动分块成若干条目，并记住自己的定位器（路径 / URL）。网页来源会自动剥除 HTML 取正文，文件来源支持 txt / md / docx / xlsx 及各类代码文件。
- **条目**是检索的最小单元。每条都带「笔记本 + 来源」的出处徽标，「全部知识」视图下一眼看清这条知识从哪来。

删除来源会连带删掉它派生的全部条目；来源支持一键刷新——文件重新读取、网页重新抓取，分块原地重建，重复导入不会产生副本。

## 检索：跨笔记本也能找到

检索依然走 Haoyue 务实的子串匹配路线：FormKC 归一化（全角半角等效）、中文二元切分、同义词扩展、短词容错，再按「标题 3 分、内容 2 分、标签 2 分」计分排序。SQLite 的分词器不认识中文，这条路实测命中率最高。

新增的 `knowledge.retrieve` 是**跨笔记本检索**：一次查询覆盖多个笔记本（或直接指定若干来源），按相关度合并排序——「我记得存过，但不记得在哪个本子里」不再是问题。标签筛选（整词精确匹配）在列表、单本检索、跨本检索里都可用。

## 桌面端：三区布局

左侧笔记本侧边栏（带默认徽标与条目计数，悬停可改名/删除），右侧上方是来源面板（文件导入、网页来源、文本来源三个入口，来源行可展开预览正文），下方是带出处徽标的条目列表。搜索输入即搜，选中笔记本时自动限定范围；标签栏一键筛选；导出按钮把整个范围渲染成一份 Markdown 备份；同义词表编辑器保存即热加载。`Ctrl+N` 新增、`Ctrl+F` 聚焦搜索、`Esc` 逐层退出。

CLI 侧 `haoyue knowledge` 命令组覆盖 list / search / add / show / delete / import / export 全套操作。

Agent 工具与界面共用同一存储：你在桌面端补的条目，Agent 下次检索就能看到；Agent 沉淀的经验，也随时可以在这里翻阅、修订或导出。
