# 进化引擎（Evolution）

进化引擎让 Haoyue 从自己的失败中学习：运行时把失败信号记入事件日志，聚合器把同类信号聚合成缺陷报告，反思回合（一个独立的 Agent turn）据此起草技能草稿，最后由你人工审阅采纳。整条链路只有一个原则——**草稿永远不会自动生效**。

## 工作流程

1. **缺陷聚合（E1）**：Runtime 把七类失败信号写入 SQLite 事件日志——工具反复失败、验证链受困、能力缺口、用户负反馈、提供商不稳（同模型短窗口内连续重试）、用户纠偏（同一会话内连续 steer）、回合中断（同一会话内连续取消）；`DefectAggregator` 按稳定指纹聚合成缺陷报告，并为每条报告标注严重度（用户负反馈恒为「高」，其余按出现次数升级）；
2. **反思回合（E2）**：反思运行器在隔离 turn 中复盘缺陷报告，产出技能草稿到 `~/.haoyue/labs`，并登记为候选（skills-candidates）；
3. **人工闸门（P3）**：候选技能等待审阅——采纳后进入正式技能目录（下一次扫描即生效），暂缓则保留在待审清单，丢弃则永久删除，同一缺陷不会再生成候选。

反自我馈送机制：已进入裁决记录（采纳、丢弃或暂缓）的指纹会被反思阶段跳过，避免同一问题反复生成候选；反思 turn 自身的会话也会被聚合器排除。

## 在 Desktop 中使用

打开“设置 → 进化”，工作台分为五个区块：

- **健康概览**：缺陷信号折算成 0-100 的健康分（优 / 良 / 中 / 差 四档），附近 7 天逐日信号趋势与按类型分布；负反馈与工具反复失败扣分最重；
- **缺陷信号**：每条报告展示类别、严重度徽章、出现次数、错误摘要与最近出现时间；
- **待审技能草稿**：可展开草稿工作台——分页预览 `skill.yaml` / `prompt.txt` / `rationale.md` 文件内容，采纳前可直接改写提示词，也可暂缓（保留待审）或丢弃（需二次确认）；
- **反思历史**：每次反思回合的触发方式（手动 / 定时 / 阈值）、处理数量与错误；
- **效果追踪**：采纳率、每个已采纳技能的实际使用次数（按 `declare_skill` 调用统计）、以及对应缺陷是否复发。

对话主界面的候选横幅提供同样的采纳 / 丢弃操作；反思无论由谁触发，完成后都会广播 `evolution.reflected` 事件，桌面端据此提醒并刷新。

## 自动反思：定时与阈值

“设置 → 进化”提供两种并存的自动触发方式：

- **定时反思**：按固定间隔在后台运行反思回合（默认 6 小时，可在 1 小时 / 6 小时 / 1 天 / 7 天之间切换，范围 30 分钟～7 天）；
- **阈值反思**：待处理的缺陷信号达到阈值（默认 5 条，范围 1～50）即提前触发，适合故障频发时加快进化节奏；两次自动反思之间至少间隔 30 分钟。

改动立即生效并持久化到配置文件；自动反思与手动反思共用同一互斥锁，冲突时自动跳过本轮，下个周期重试。全部关闭后仅手动（或通过 `evolution.reflect` IPC / 定时任务）触发。

## CLI：haoyue evolve

进化引擎的检视与人工闸门同样可以在终端完成：

| 命令 | 说明 |
| --- | --- |
| `haoyue evolve defects` | 聚合缺陷报告，显示健康分与明细表 |
| `haoyue evolve pending` | 列出待审草稿（含状态） |
| `haoyue evolve history` | 反思回合历史（`--limit` 控制条数） |
| `haoyue evolve stats` | 采纳率、技能使用与缺陷复发统计 |
| `haoyue evolve decide <指纹> adopt\|reject\|defer` | 人工终审；指纹可用前缀匹配，`adopt` 可加 `--prompt "…"` 采纳前改写提示词 |

## 相关 IPC 方法

| 方法 | 说明 |
| --- | --- |
| `evolution.inspect` | 聚合缺陷报告，附健康分、近 7 天趋势与按类型/工具分布（可传 `limit` 限制扫描条数） |
| `evolution.reflect` | 发起反思回合，立即返回 `{started:true}` |
| `evolution.pending-list` | 列出待审技能草稿（含状态与草稿文件内容，超长文件自动截断） |
| `evolution.decide` | 人工终审：`decision` 取 `adopt` / `reject` / `defer`；`adopt` 可附 `prompt` 改写提示词 |
| `evolution.history` | 反思回合历史（`limit` 缺省 20） |
| `evolution.stats` | 进化效果统计：采纳率、技能使用次数与缺陷复发 |
| `evolution.config.get` / `evolution.config.set` | 读取或更新自动反思配置（定时与阈值两组参数） |

::: tip
反思产出的草稿技能存放在 `~/.haoyue/labs`，采纳前的候选不会进入技能扫描路径，对会话零影响。
:::
