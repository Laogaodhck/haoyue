# 进化引擎：从失败中长出技能

Haoyue 不只是记录错误——它把错误变成下一次会话的能力。进化引擎完整观察运行过程中的失败信号，经反思回合提炼成技能草稿，最终由你决定哪些进入正式技能库。

## 四步闭环

```text
失败信号 → 缺陷聚合 → 反思回合 → 技能草稿 → 人工审阅
```

- **信号采集**：工具反复失败、验证链连续受困、能力缺口（试图调用不存在的技能）、以及你在对话中给出的负反馈，都会写入本地事件日志；
- **缺陷聚合**：同类信号按稳定指纹合并，重复出现 10 次的问题只占一行报告；
- **反思回合**：一个独立的 Agent turn 复盘这些报告，把"下次该怎么做"写成技能草稿，存放在 `~/.haoyue/labs`；
- **人工闸门**：草稿永远等待你的裁决——采纳即进入正式技能目录，丢弃则永久删除且同一缺陷不再重复生成。

## 在 Desktop 中操作

设置中心的「进化」页把整条链路可视化：缺陷信号一览、一键「立即反思」、以及待审技能草稿的采纳 / 丢弃。反思在后台进行，完成后桌面端会主动提醒你审阅。

不想手动触发？打开「自动反思」开关，Runtime 会按你选择的间隔（1 小时到 7 天）在后台自动复盘。无论哪种方式，产出都不会未经审阅自动生效。

## 与记忆体系的分工

- **记忆（MEMORY.md）**沉淀事实与约定，每次会话注入；
- **进化**沉淀可复用的操作流程，以技能形式在需要时被调用。

两者共同构成 Haoyue 随使用不断成长的本地知识资产。
