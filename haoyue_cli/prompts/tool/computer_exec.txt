Runs native OS shells for scripted system work on whichever OS family the host is (the tool detects Windows / Linux / macOS itself — you never need to guess). 'kind' picks the interpreter: 'auto' (or omitted) resolves to PowerShell on Windows and bash on Linux/macOS; 'powershell' (system scripting: files, registry, services, processes, WMI/CIM queries) and 'cmd' (batch commands) exist only on Windows; 'bash' (POSIX shell utilities, /proc, package managers) exists only on Linux/macOS; 'python' runs on any host where Python is installed (detection is OS-aware: python.exe/py launcher on Windows, python3 on POSIX). Unsupported kinds fail with a precise message naming the OS and the correct kind — switch dialects accordingly, e.g. `Get-Process` (PowerShell) vs `ps aux` (bash), `reg query` vs `/proc` and `sysctl`. computer_sysinfo reports the platform line and Python version up front; read it first on an unfamiliar host.

Returns stdout/stderr and the exit code; a nonzero exit code marks the call as failed. Use 'cwd' for the working directory (defaults to the user profile) and 'timeout_seconds' for long-running commands (default 60, max 600). Output is captured as UTF-8 (Chinese text is safe). Elevation: commands run as the current user — actions needing administrator/root rights pop a UAC/sudo prompt on screen that the user must approve. Destructive commands (mass deletion, registry/system-config changes, service or firewall changes, disk operations, package removal) require explicit user confirmation in the conversation first, same as destructive GUI actions.
