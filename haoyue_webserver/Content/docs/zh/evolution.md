# 进化引擎（Evolution）

进化引擎让 Haoyue 从自己的失败中学习：运行时把失败信号记入事件日志，聚合器把同类信号聚合成缺陷报告，反思回合（一个独立的 Agent turn）据此起草技能草稿，最后由你人工审阅采纳。整条链路只有一个原则——**草稿永远不会自动生效**。

## 工作流程

1. **缺陷聚合（E1）**：Runtime 把工具失败、验证链受困、能力缺口与用户负反馈写入 SQLite 事件日志；`DefectAggregator` 按（类别、工具、归一化错误）计算稳定指纹，聚合成缺陷报告；
2. **反思回合（E2）**：反思运行器在隔离 turn 中复盘缺陷报告，产出技能草稿到 `~/.haoyue/labs`，并登记为候选（skills-candidates）；
3. **人工闸门（E4）**：候选技能等待审阅——采纳后进入正式技能目录（下一次扫描即生效），丢弃则永久删除，同一缺陷不会再生成候选。

反自我馈送机制：已进入裁决记录（采纳或丢弃）的指纹会被反思阶段跳过，避免同一问题反复生成候选。

## 在 Desktop 中使用

打开“设置 → 进化”：

- **缺陷信号**：查看最近运行事件聚合出的可改进点（类别、次数、错误摘要、最近出现时间）；
- **立即反思**：手动发起一次反思回合，turn 在后台运行，完成后页面自动刷新并以通知说明结果；
- **待审技能草稿**：审阅反思产出的候选技能，逐一采纳或丢弃（丢弃需要二次确认）。

对话主界面的候选横幅提供同样的采纳 / 丢弃操作；反思无论由谁触发，完成后都会广播 `evolution.reflected` 事件，桌面端据此提醒。

## 自动反思

在“设置 → 进化”中打开**自动反思**后，Runtime 会按固定间隔在后台运行反思回合（默认 6 小时，可在 1 小时 / 6 小时 / 1 天 / 7 天之间切换，范围 30 分钟～7 天）。改动立即生效并持久化到配置文件；自动反思与手动反思共用同一互斥锁，冲突时自动跳过本轮，下个周期重试。

关闭自动反思后仅手动（或通过 `evolution.reflect` IPC / 定时任务）触发。

## 相关 IPC 方法

| 方法 | 说明 |
| --- | --- |
| `evolution.inspect` | 聚合缺陷报告（可传 `limit` 限制扫描条数） |
| `evolution.reflect` | 发起反思回合，立即返回 `{started:true}` |
| `evolution.pending-list` | 列出待审技能草稿 |
| `evolution.decide` | 人工终审：`decision` 取 `adopt` 或 `reject` |
| `evolution.config.get` / `evolution.config.set` | 读取或更新自动反思配置 |

::: tip
反思产出的草稿技能存放在 `~/.haoyue/labs`，采纳前的候选不会进入技能扫描路径，对会话零影响。
:::
