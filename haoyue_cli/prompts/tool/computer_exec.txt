Runs native Windows shells for scripted system work: 'kind' picks the interpreter — 'powershell' (system scripting: files, registry, services, processes, WMI/CIM queries), 'cmd' (batch commands and console utilities), 'python' (data processing, automation libraries). Returns stdout/stderr and the exit code; a nonzero exit code marks the call as failed. Use 'cwd' for the working directory (defaults to the user profile) and 'timeout_seconds' for long-running commands (default 60, max 600).

Prefer this tool over clicking through GUIs whenever the goal can be expressed as a script: bulk file operations, system information, installing or querying software, network diagnostics, parsing data. Use the GUI tools for interactive apps instead. Output is captured as UTF-8 (Chinese text is safe). Elevation: commands run as the current user — actions needing administrator rights pop a UAC prompt on screen that the user must approve. Destructive commands (mass deletion, registry changes, service or firewall changes, disk operations) require explicit user confirmation in the conversation first, same as destructive GUI actions.
