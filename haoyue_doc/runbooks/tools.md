# 内置工具 Runbook（how-to-use）

> 护栏：`haoyue_tests/RunbookCoverageTests` 保证每个注册的 `ITool` 都有 `## <tool-name>` 章节。
> 新增工具时先在本文件补章节，再合入代码（见 [README](README.md)）。

## update_plan

- **用途**：维护当前回合的任务计划清单（计划模式的核心载体），让复杂任务进度可见。
- **参数**：计划条目数组（含状态：pending / in_progress / completed）。
- **何时用**：任务 ≥3 个可独立验证的步骤时；计划被用户新输入推翻时同步更新。
- **何时不用**：单一简单操作（读一个文件、跑一条命令）——直接做，不要为计划而计划。
- **失败表现**：条目状态机非法（如跳过 in_progress 直接收尾）会被拒绝，返回 params 校验错误。

## memory_save

- **用途**：把值得跨任务保留的事实（用户偏好、项目约定、环境要点）写入工作区记忆文件 MEMORY.md，后续回合自动注入系统提示。
- **参数**：`content` 必填（一句话）；`topic` 可选标签。
- **何时用**：用户明确表达偏好、发现未成文的项目约定、排查出环境坑时随手记一条。
- **何时不用**：任务进度类信息（会话历史已覆盖）；密钥凭据；用户未确认的推测。
- **失败表现**：content 为空返回校验错误；重复内容按行去重返回「已存在」；文件不可写返回 IO 错误信息。

## read_file

- **用途**：读取文件内容（支持行号范围与图片）。
- **参数**：`path` 必填；可选行范围。
- **何时用**：查看代码/配置/文档；大文件先用范围读取避免撑爆上下文。
- **何时不用**：只需要文件列表时用 list_dir/glob；需要搜索内容时用 grep。
- **失败表现**：文件不存在返回 notFound 语义错误；二进制文件拒绝读取。

## write_file

- **用途**：创建或整体覆写文件。
- **参数**：`path`、`content` 必填。
- **何时用**：新建文件；或重写幅度大到 edit 不可读时。
- **何时不用**：局部修改——永远优先 edit_file，避免整文件覆写吞掉他人改动。
- **失败表现**：只读/计划模式下被拒绝；路径越出工作区被拒绝。

## edit_file

- **用途**：精确字符串替换式修改。
- **参数**：`path`、`old_string`、`new_string`；`old_string` 必须唯一匹配，多处命中时扩上下文。
- **何时用**：一切局部代码/文本修改。
- **何时不用**：全文重写、格式化整文件。
- **失败表现**：old_string 不唯一或不匹配 → 明确报错，不会盲目替换。

## list_dir

- **用途**：列出目录结构。
- **参数**：`path`；可选深度。
- **何时用**：了解项目布局、定位入口文件。
- **何时不用**：已知文件名模式时用 glob 更高效。
- **失败表现**：目录不存在 → 错误返回。

## glob

- **用途**：按模式（`**/*.ts` 等）匹配文件路径。
- **参数**：`pattern` 必填，可选 `path` 根目录。
- **何时用**：按命名模式找文件（所有测试、所有组件）。
- **何时不用**：按内容找 → grep。
- **失败表现**：无匹配返回空列表（不是错误）。

## grep

- **用途**：基于 ripgrep 的正则内容搜索。
- **参数**：`pattern` 必填；可选 glob 过滤、大小写敏感、上下文行数。
- **何时用**：定位符号定义、调用点、错误文本。
- **何时不用**：按文件名找文件。
- **失败表现**：非法正则 → 参数错误；无匹配 → 空结果。

## bash

- **用途**：执行 shell 命令（构建、测试、git、系统查询）。
- **参数**：`command` 必填；有超时上限。
- **何时用**：运行验证命令、批量操作、需要真实执行环境的场景。
- **何时不用**：能用专用工具（read/edit/glob/grep）完成的文件操作——专用工具更安全且可审计。
- **失败表现**：非零退出码原样返回 stderr/stdout；超时被取消并标记。

## web_search

- **用途**：联网搜索，返回结果块。
- **参数**：`query` 必填；可选 freshness 时间过滤、域名过滤。
- **何时用**：时效性问题、外部 API/文档查询。
- **何时不用**：agent.networkEnabled=false 时该工具被整体剥离，不可调用。
- **失败表现**：网络错误/限流以错误返回，agent 应降级为本地推理并告知用户。

## web_fetch

- **用途**：抓取 URL 并转 Markdown 供分析。
- **参数**：`url`、`prompt` 必填。
- **何时用**：读取用户给的链接、查文档详情页。
- **何时不用**：二进制资源（图片/压缩包）——下载应走 bash。
- **失败表现**：重定向会提示跟随；404/反爬返回明确错误。

## capture_screen

- **用途**：截取屏幕/窗口画面，作为图像输入辅助 GUI 调试。
- **参数**：目标区域/窗口可选。
- **何时用**：用户描述 GUI 问题、需要核对桌面状态时。
- **何时不用**：纯命令行/代码问题。
- **失败表现**：无显示环境（服务/CI）时返回不可用错误。

## knowledge_search

- **用途**：对知识库做高容错检索（同义/错字容忍）。
- **参数**：`query` 必填；workspace/global 作用域可选。
- **何时用**：回答前先查用户沉淀的知识，避免重复提问。
- **何时不用**：纯代码问题（用 grep）。
- **失败表现**：无命中返回空列表。

## knowledge_save

- **用途**：保存/更新知识条目（同题 upsert）。
- **参数**：`title`、`content` 必填；tags 可选；作用域可选。
- **何时用**：用户明确要求记住某结论/偏好/事实时。
- **何时不用**：临时性会话内容——不要把噪声写进知识库。
- **失败表现**：内容超长（≤8000 字符）被拒。

## knowledge_forget

- **用途**：按 id 删除知识条目。
- **参数**：`id` 必填。
- **何时用**：用户指出某条知识过时/错误时。
- **失败表现**：id 不存在 → notFound。

## delegate_task

- **用途**：把子任务委派给独立上下文的子 agent 执行（隔离探索、批量调研）。
- **参数**：任务描述 + 可选子 agent 类型。
- **何时用**：子任务产出量大、会污染主上下文时（大范围搜索、长文档提炼）。
- **何时不用**：简单单步操作——委派开销不值得。
- **失败表现**：子 agent 失败时错误回传主回合，不静默吞掉。

## declare_skill

- **用途**：手动加载一个未命中关键词触发的技能，对当前回合生效。
- **参数**：`name` 必填（技能目录名）。
- **何时用**：用户意图明显属于某技能但措辞不含触发词时（召回兜底）。
- **失败表现**：技能名不存在或被禁用 → 明确报错；只读操作，不改任何文件。
