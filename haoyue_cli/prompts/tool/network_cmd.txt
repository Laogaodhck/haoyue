Runs one logical network-ops command chosen from the directory in the parameter schema: `command` (e.g. ping, interfaces, routes, connections, arp, dns_lookup, dns_flush, traceroute, netsh on Windows; ip, nmcli, ethtool on Linux), optional `target` (host, IP or interface name — required by ping/traceroute/dns_lookup/ethtool), and optional `args` (extra arguments passed one item each, e.g. ["-n", "4"]).

The runtime maps the logical command onto the platform binary automatically (Windows: ipconfig /all, route print, netstat -ano, tracert…; Linux: ip addr, ip route, ss -tulpn, traceroute…) and runs it without a shell, so pipes/redirects/chaining are not possible — request the full output and filter it yourself. Output includes the exit code. State-changing commands are refused when the user disabled mutating ops (networkOps.allowMutating=false); on Linux ping defaults to -c 4 so the call always terminates.
