Inspects the desktop and the foreground application's UI structure and returns a list of interactive elements with names, control types, bounding boxes, center coordinates, and stable element Ids. Use this before clicking anything in an unfamiliar window: clicking by element Id ('element_click' on the computer tool) is far more reliable than guessing pixel coordinates from a screenshot. Set 'take_screenshot': true to also attach an image of the current screen. Element snapshots age quickly — re-inspect after switching windows or when a click on an Id misses.
