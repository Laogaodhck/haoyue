Detects and repairs browser homepage hijacking. action='detect' (read-only) inspects Chrome/Edge policy registry keys (HKCU and HKLM), the IE/Shell Start Page, Chrome/Edge profile Preferences JSON, Firefox prefs.js, and browser desktop/taskbar shortcuts for forced or suspicious homepage URLs. action='repair' first backs every finding up to ~/.haoyue/browser-repair-backups/, then removes forced policies, restores the homepage (homepage parameter, default about:blank), clears hijacked shortcut arguments, and rewrites preference files; entries needing administrator or root rights (HKLM, /etc policies) are reported as failures with guidance instead of aborting. Always run detect first and get explicit user confirmation before repair.
