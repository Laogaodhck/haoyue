Scans the local computer to locate targets for follow-up actions. With target='hardware' it reports CPU, memory modules, GPU, physical disks, logical volumes, network adapters, and motherboard/BIOS details. With target='filesystem' it walks a directory tree (path, max_depth, max_entries, show_hidden) listing structure and file sizes plus the ten largest files, and skips unreadable directories with a permission note instead of failing. Read-only and safe to run anytime; feed the results into computer_exec or the file tools to act on what you found.
