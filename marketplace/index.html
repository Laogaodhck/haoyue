玥浩玥技能市场 官方目录同步

浩玥（Haoyue）本地 Agent 运行时的官方技能与连接器目录。数据由运行时单源（OfficialSkillCatalog / connectors/）自动导出，经契约护栏测试防漂移；社区技能经 PR 合入后即可在站内浏览。

贡献一个技能 / 连接器

  1. Fork 本仓库，在 marketplace/community/<slug>/ 下放入你的技能文件（裸 .md 提示词，或含 skill.yaml + prompt.txt 的 .zip）。
  2. 技能目录规范与字段说明见 marketplace/CONTRIBUTING.md（name / description / version / triggers / allowed-tools / parameters）。
  3. 提交 PR 并勾选模板中的自查清单（不含密钥、提示词可独立执行、已实测）。
  4. 合入后站内即可浏览；用户通过 haoyue skill import <文件> 一键导入，或在桌面端「技能导入」选择下载文件。
  5. 连接器类贡献遵循 connectors/schema/connector.schema.json，提交到 connectors/ 目录。
