Reads system configuration, settings, and running processes. section='config' returns the OS edition/build, machine identity, uptime, locale and time zone, power scheme, displays, page file, .NET runtime version, and Python availability (when Python is missing, computer_exec kind=python will not work — say so and suggest installing it or setting computerUse.pythonPath). section='processes' lists running processes sorted by CPU with an optional name filter and limit. Read-only; use the output to decide follow-up actions (kill or restart a process, free disk space, change settings) via computer_exec with explicit user confirmation for anything destructive.
