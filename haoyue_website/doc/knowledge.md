# 知识库：让经验可检索

如果说记忆（MEMORY.md）是每次对话都注入的「工作备忘」，知识库就是可按需检索的「档案柜」。Agent 在对话中自动往里存事实、命令、踩坑与修复方式，下次遇到相关问题时按语义检索取回——你也可以在桌面端和 CLI 里手动维护这份资产。

## 为什么子串匹配反而更好

市面上大部分检索方案依赖分词，而 SQLite 的分词器根本不认识中文。Haoyue 知识库选择了一条务实的路：查询先做 FormKC 归一化（全角半角等效）、中文二元切分（无空格长句也能命中）、同义词扩展和短词容错，再用子串匹配计分——标题 3 分、内容 2 分、标签 2 分，覆盖率优先排序。实测中英混排查询的命中率远高于直接套用英文分词方案。

## 这一次新增了什么

- **标签体系**：标签按整词精确匹配（`build` 不会误伤 `buildtool`，全角逗号也能正确拆分），`knowledge.tags` 聚合所有标签与计数，列表和检索都能按标签筛选；
- **一键导出**：整个知识库渲染成一份带范围、时间与标签的 Markdown 文档，桌面端走系统保存对话框，CLI 写文件或直接输出，备份与分享都省事；
- **同义词编辑器**：`~/.haoyue/knowledge/synonyms.txt` 一直是检索调优的隐藏入口，现在桌面端可以直接读写它——每行「关键词 = 同义词1, 同义词2」，保存即热加载，内置技术同义词表自动合并其下；
- **编辑不再分叉**：过去改一个条目的标题会生成一条新知识，现在编辑按 id 原地保存，改名也安全；
- **CLI 导入导出**：`haoyue knowledge import` 批量导入文件（逐文件汇报、失败不中断），`haoyue knowledge export` 一条命令备份全部条目。

## 在哪里操作

桌面端「知识库」页把上面所有能力摆在同一层：标签栏一键筛选、工具栏下载按钮导出、滑杆按钮打开同义词编辑器；`Ctrl+N` 新增、`Ctrl+F` 聚焦搜索、`Esc` 逐层退出。CLI 侧 `knowledge` 命令组覆盖 list / search / add / show / delete / import / export 全套操作。

Agent 工具与界面共用同一存储：你在桌面端补的条目，Agent 下次检索就能看到；Agent 沉淀的经验，也随时可以在这里翻阅、修订或导出。
